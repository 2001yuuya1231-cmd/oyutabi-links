# oyutabi-links

Instagram [@onsen_tabi_travel](https://www.instagram.com/onsen_tabi_travel/)（おゆたび）で
紹介した温泉宿の予約リンクページ。

- 公開URL: https://2001yuuya1231-cmd.github.io/oyutabi-links/
- 中身は `index.html` と `img/` だけ。手で編集しない
- 生成元: `oyutabi/tools/build_link_page.js`（投稿カレンダーと企画フォルダから自動生成）

```bash
node oyutabi/tools/build_link_page.js --outdir /path/to/oyutabi-links
```

リンクはアフィリエイト広告を含みます。
